## セットアップ & 起動手順
1. 依存関係をインストールします。
   ```bash
   npm install
   ```
2. 開発サーバーを起動します。(http://localhost:5173)
   ```bash
   npm run dev
   ```
3. ビルドを行う場合
   ```bash
   npm run build
   ```
